## 1. aaPanel Deployment Guide

### Option A: Static Deployment (Fastest & Recommended)

1. **Build the production bundle:**
   ```bash
   npm install
   npm run build
   ```
2. In aaPanel, navigate to **Website** > **Add site**.
3. Enter your domain (e.g. `gofayda.com`), choose type **HTML/PHP**, and submit.
4. Go to **Site settings** > **Site directory** tab:
   - Set **Running directory** to `/dist` (or copy contents of `dist/` into `/www/wwwroot/yourdomain.com`).
5. Go to **URL rewrite** tab and add the SPA fallback:
   ```nginx
   location / {
       try_files $uri $uri/ /index.html;
   }
   ```
6. In **SSL** tab, generate a free **Let's Encrypt** SSL certificate and enable **Force HTTPS**.

## 2. Issue 1: Default aaPanel Welcome Page Showing

### **Symptom**
After creating a new website in aaPanel and opening the domain, you see the default placeholder page:
> *"Congratulations, the site is created successfully! This is the default index.html, this page is automatically generated by the system..."*

### **Root Cause**
aaPanel places a placeholder `index.html` in the root folder (`/www/wwwroot/yourdomain.com`), while your built React app is inside `/dist`.

### **Solutions**
- **Fix 1 (Site Directory Setting):** In aaPanel, open **Website** > Click your domain > **Site directory** > Change **Running directory** to `/dist` > Click **Save**.
- **Fix 2 (Move Files):** Open aaPanel **Files** > Delete default `index.html` & `404.html` from the site root > Move all files from inside `dist/` directly into the site root.

## 3. Issue 2: 404 Not Found on Page Refresh / Sub-Routes

### **Symptom**
The homepage opens fine, but refreshing or accessing sub-routes returns an `Nginx 404 Not Found` error.

### **Root Cause**
Vite + React is a client-side Single Page Application (SPA). Nginx must route all virtual URLs back to `/index.html`.

### **Solution**
In aaPanel, go to **Website** > Click domain > **URL rewrite**, and paste:
```nginx
location / {
    try_files $uri $uri/ /index.html;
}
```
Click **Save**.

## 4. Issue 3: Admin Panel Changes & Persistence Explanation

### **Symptom / Question**
When editing prices or plan details in the Admin Panel, there is no manual "Save" button.

### **Behavior & Root Cause**
- **Instant Live Auto-Save:** The Admin Panel saves in real-time as you type. Changes are instantly stored in React state and browser `localStorage`.
- **Viewing Changes:** Simply click the `✕` close button in the top right corner of the Admin Panel to see the updated site immediately.

### **How to Make Changes Global for ALL Visitors Worldwide:**
1. **Permanent Source Code Edit:** Update default values in `src/data/hostingData.js`, then run `npm run build`.
2. **Export / Import JSON:** In the Admin Panel, go to **Backup & Reset** > **Export JSON**. You can import this JSON file on any server or browser instance.

## 5. Issue 4: Platform-Specific Binary Mismatches on Build

### **Symptom**
Rollup/esbuild errors when building across different operating systems (Windows vs Linux).

### **Solution**
In your aaPanel Terminal (or local terminal), run a clean install:
```bash
npm install
npm run build
```

## 7. ⚡ aaPanel Terminal Command Cheat Sheet

```bash
# Navigate to website root directory
cd /www/wwwroot/yourdomain.com

# Check directory contents
ls -la

# Pull newest code from GitHub repository
git pull origin main

# Re-install dependencies
npm install

# Build for production
npm run build

# Verify build output
ls -la dist/

# Test and reload Nginx
nginx -t
systemctl reload nginx
```
